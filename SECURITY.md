# Security Policy

## Supported versions

xel has no releases yet. Until 1.0, only the latest commit on `main` and the most
recent release receive fixes.

## Reporting a vulnerability

Report privately through
[GitHub Security Advisories](https://github.com/oddurs/xel/security/advisories/new).
Do not open a public issue.

xel opens workbook files and runs formulas, SQL, and Python inside them, so reports
about code execution from an untrusted workbook are especially welcome.

## What to expect

- Acknowledgement within 3 days.
- An assessment and a planned fix date within 14 days.
- Credit in the advisory and changelog, unless you prefer otherwise.
