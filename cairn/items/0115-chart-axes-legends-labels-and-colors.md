## Problem

Default charts are rarely good enough to share.

## Proposal

Inspector controls for titles, axis ranges and number formats, legend position, data labels, and series colors from an accessible default palette.

## Acceptance criteria

- [ ] Axis labels use the source column's display format
- [ ] Every formatting change is one undo step
