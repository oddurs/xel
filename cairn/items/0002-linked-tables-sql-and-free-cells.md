## Ships

Workbooks become relational: tables link to each other, SQL query blocks compute over them, sheets hold free A1 cells beside tables, and each table has saved filtered, sorted, and grouped views.

## Done when

- [ ] A two-table workbook (orders linked to customers) can be built, queried with SQL, and summarized in a calc block without leaving the app
- [ ] Every p0 item in this milestone is done and the v0.2.0 release is published

## Explicitly not in this milestone

- Excel file import or export (v0.3)
- Kanban, calendar, gallery, or form views (later)
