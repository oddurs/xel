## Ships

The promise: an Excel user can open an .xlsx in xel, work with it as typed, linked tables using Excel formulas, SQL, and Python, and save a .xel file any SQLite tool can read, with a file format and Python API that will not break without a major version.

## Done when

- [ ] The file format and Python API are documented and declared stable
- [ ] Performance and accessibility targets pass and are gated in CI where measurable
- [ ] Install is one command (`brew install --cask xel`) and updates arrive automatically
- [ ] No new features: every item here is stability, completeness, documentation, or packaging

## Explicitly not in this milestone

- Charts and pivot tables
- Real-time collaboration
- Platforms other than macOS
