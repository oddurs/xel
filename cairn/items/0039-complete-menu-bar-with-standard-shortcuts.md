## Problem

Every command should be discoverable and reachable without the mouse.

## Proposal

File, Edit, View, Insert, Table, Format, Window, and Help menus. Every v0.1 command appears in a menu with a standard shortcut where macOS has one.

## Acceptance criteria

- [ ] No command exists only in a context menu or toolbar
- [ ] Shortcuts do not collide, checked by a test over the menu definition
