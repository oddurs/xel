## Problem

Views need to be created and switched quickly.

## Proposal

Views appear under their table in the sidebar. A toolbar control edits filter, sort, group, and hidden fields for the current view with live preview.

## Acceptance criteria

- [ ] Creating a view, filtering, and switching back is undoable
- [ ] The default view cannot be deleted
