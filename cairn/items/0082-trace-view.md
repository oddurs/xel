## Problem

Lineage is only useful if it can be seen.

## Proposal

A trace view in the inspector shows the selected value's inputs and dependents; clicking a node selects it in the grid. The grid outlines precedents in matching colors.

## Acceptance criteria

- [ ] Keyboard and VoiceOver can walk the trace
